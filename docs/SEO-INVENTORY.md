## Editorial workflow

1. Define a distinct reader need and check the inventory for overlap.
2. Supply verified facts and subject expertise. Do not invent keyword metrics, projects, sources, dates, or performance.
3. Write an independently useful page, assign factual review, and link it from an appropriate hub.
4. Add the content to src/content, then rebuild. The sitemap, structured data, security policy, and inventory update automatically.
5. Run structural and browser checks. Inspect copy and mobile rendering before release.
6. Set a real publication date only when publication is approved; record material revisions accurately.

## After deployment

Verify the canonical domain in Google Search Console and Bing Webmaster Tools using DNS or the verification fields in src/config.mjs. Submit https://shahirsalehi.com/sitemap.xml to each service. Inspect representative live URLs, redirects, robots.txt, rendered HTML, and indexing. Submission does not guarantee indexing or rankings. Live keyword research and client-approved case studies are separate editorial work.
